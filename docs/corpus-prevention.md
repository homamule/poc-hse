# Corpus pilote — prévention des risques professionnels

Corpus pédagogique limité de **quatre articles distincts** du Code du travail, destiné à exercer la collecte par lot. Il **ne prétend pas** à l’exhaustivité HSE ni à couvrir l’ensemble des obligations de prévention.

Code attendu : **Code du travail**, `LEGITEXT000006072050`.

## Limites

- Les identifiants sont des **versions fixées explicitement** dans `config/articles-prevention.json`.
- Une recollecte de ces identifiants **ne découvre pas automatiquement** une nouvelle version d’article.
- L’état, les dates et les relations seront examinés **dans les réponses collectées** ; ils ne sont pas affirmés ici.
- Aucun lien métier (graphe, obligations, concordance) ne doit être inventé à partir de ces descriptions pédagogiques.
- `config/articles-pilot.json` reste le lot des **trois versions historiques** de L4121-1 ; ce corpus-ci porte sur **quatre articles distincts**.
